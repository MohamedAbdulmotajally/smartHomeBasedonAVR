# Smart Home Based on AVR

This project implements a basic smart home system using AVR microcontrollers. It includes source code for the microcontroller logic and simulation files for circuit design using Proteus.

## Overview

This project demonstrates how a home automation system can be built using AVR-based microcontrollers to control and monitor devices like lights, fans, and sensors (e.g., temperature, motion, etc.).

## Features

- Control home devices using AVR microcontroller logic.
- Monitor sensor inputs for automation or alerting.
- Circuit simulation provided using Proteus design files.
- Code written in C and compiled using AVR-GCC or Atmel Studio.

## Requirements

- **AVR Microcontroller** (e.g., ATmega16/32)
- **AVR-GCC Toolchain** or **Atmel Studio**
- **Proteus Design Suite** (for simulation)

## Getting Started

1. **View the circuit:**
   - Open the files in the `design on proteus` folder using Proteus.

2. **Build the code:**
   - Navigate to the `code` folder.
   - Compile the code using `avr-gcc` or open the project in Atmel Studio.
   - Flash the generated `.hex` file to your AVR microcontroller.

3. **Run the simulation:**
   - Use Proteus to simulate the microcontroller behavior and device interaction.
